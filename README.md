# 🎁 WishLog — Telegram-бот для списка желаний

## О проекте

**WishLog** — Telegram-бот, предназначенный для создания и управления списками желаний. Проект помогает пользователям собирать идеи для подарков, хранить их в одном месте и делиться ими с другими людьми.

Основная идея проекта — упростить выбор подарков и сделать процесс обмена пожеланиями более удобным.

## Цели проекта

- Создать удобный инструмент для ведения списков желаний.
- Упростить обмен идеями для подарков между пользователями.
- Помочь выбирать подарки с учётом пожеланий получателя.
- Обеспечить доступ к основным функциям через Telegram.
- Создать основу для дальнейшего развития и добавления новых возможностей.

## Основные возможности

Проект предназначен для работы со списками желаний. В зависимости от реализованного функционала пользователи могут добавлять желания, просматривать списки и делиться ими.

Дополнительные возможности описываются по мере их реализации.

## Используемые технологии

- **Python** — основной язык программирования.
- **aiogram** — взаимодействие с Telegram Bot API.
- **PostgreSQL** — работа с базой данных.
- **SQLite** — хранение данных.
- **python-dotenv** — загрузка настроек из переменных окружения.
- **Git** — контроль версий и совместная разработка.

Фактические зависимости проекта указаны в файле `requirements.txt`.

## Установка и запуск

### Требования

Для запуска проекта необходимы:

- установленный Python;
- Git;
- созданный Telegram-бот и его токен, полученный через [@BotFather](https://t.me/BotFather).

### 1. Клонирование репозитория

```bash
git clone https://github.com/dozddd/wishlog.git
cd wishlog
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows:

```bash
.venv\Scripts\activate
```

Активация в Linux и macOS:

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка окружения

Создайте файл `.env` на основе `.env.example`.

Укажите необходимые переменные окружения. Например:

```env
BOT_TOKEN=your_telegram_bot_token
```

Используйте названия переменных, предусмотренные конфигурацией проекта.

**Важно:** файл `.env` содержит конфиденциальные данные. Не добавляйте его в репозиторий и не публикуйте токен Telegram-бота.

### 5. Запуск приложения

Из корневой папки проекта выполните:

```bash
python -m bot.main
```

## Структура проекта

```text
wishlog/
├── bot/
│   ├── config.py
│   └── main.py
├── .env.example
├── .gitignore
├── requirements.txt
└── README.md
```

- `bot/` — исходный код приложения.
- `config.py` — настройки приложения.
- `main.py` — точка входа приложения.
- `.env.example` — пример файла с переменными окружения.
- `.gitignore` — список файлов, которые Git не должен отслеживать.
- `requirements.txt` — список зависимостей Python.
- `README.md` — документация проекта.

Структура может расширяться по мере добавления новых модулей.
